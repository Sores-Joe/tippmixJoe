# Tippmix Pro 5.2 – automatikus online piacfigyelő

Nem kell kézzel oddsokat beírni. A `data/live.json` nemzetközi oddsadataiból a felület automatikusan kiszámolja az árrésmentesített piaci konszenzust és megjeleníti a legjobb külső árakat (1X2). Legalább két teljes fogadóirodai 1X2 piac szükséges.

**Korlát:** A TippmixPro.hu hivatalos oddsainak automatikus, engedélyezett forrása még nincs integrálva. Külső oddsot nem állítunk be TippmixPro-oddsként. A megjelenített fair odds nem független sportstatisztikai modell és nem garantál pozitív EV-t.

## Frissítés
Készíts JSON biztonsági mentést. A GitHub Pages repository gyökerében csak az `index.html`, `sw.js`, `README.md` fájlokat cseréld. A `.github`, `scripts`, `data` mappákat hagyd változatlanul. A meglévő helyi tárolási kulcsot megtartottuk.
